# RealEstateInfoApp

This project is a simple real estate information viewer app with:
- A native Android app (Jetpack Compose + Retrofit)
- A lightweight Flask backend API
- SQLite database for storing property data

## Features

- View list of real estate properties
- Display area, rooms, floor, and other info
- Connects to local Flask API
- Uses SQLite for demo data

## Project Structure

- `/backend` – Python Flask API + database
- `/mobile` – Android app using Kotlin
- `RealEstateInfoApp_Progress_Report.md` – Progress documentation
